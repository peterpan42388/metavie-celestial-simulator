# Asset and dependency provenance

All geometry and synthetic fixtures are original procedural work in this repository, licensed MIT. Only original illustrative textures are bundled; no star catalogues, photographs or font files are bundled. Canvas labels use host sans-serif; pin host fonts when comparing fallback pixels.

Three.js 0.180.0: MIT, https://github.com/mrdoob/three.js/tree/r180 (license in node_modules/three/LICENSE).
Playwright 1.56.1: Apache-2.0, https://github.com/microsoft/playwright/tree/v1.56.1 (development/recording only). Chromium is obtained through Playwright; its bundled third-party notices apply. FFmpeg is an external local recording prerequisite; distribution/license configuration is the operator's responsibility. No binary is bundled.

Historical `evidence/` provenance records preserve the license value embedded when their pinned source commits were recorded; those archived snapshots are not a declaration of this revision's license.

Visual upgrade pack: 22 original illustrative PNG maps (512×256 and 128×64), generated by `scripts/generate-assets.mjs` from `src/surfaces.js`. All are MIT, created by Tech Leo / Metavie contributors. The complete file/size/creator/source/hash register is `assets/ASSET_MANIFEST.json`. No NASA/USGS pixels or other third-party imagery were sampled; these are stylized maps, not scientific reconstructions of surface geography. Saturn rings, star coordinates, halo textures and the bitmap glyph/label atlas are original code-defined MIT assets. No externally licensed font is shipped. External image packs are the consumer's responsibility and must retain their own audited attribution; they are not included in this manifest.
